# Directory listing

* `88x31/` - Various buttons around the internet. Some from friends, some from not friends. All of them are intended to be reused and redistributed - that's the point of an 88x31, after all. Even so, I prefer to hotlink. This folder exists so that if the websites disappear, or limit/throttle a specific user/IP, the badges don't break.
* `censorpandas/` - Content with the NC-17 rating has been given [the RTA label](<https://www.rtalabel.org/>).
* `disablejs/` - Favicons for various popular websites; used with the scare tactics popup from [https://disable-javascript.org](<https://disable-javascript.org>).
* `signal.png` - Signal QR code. Used on `/contact` and `/signal`.
