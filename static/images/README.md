# Directory listing

* `88x31/` - Various buttons around the internet. Some from friends, some from not friends. All of them are intended to be reused and redistributed - that's the point of an 88x31, after all. I'd prefer to hotlink, but certain browser extensions like NoScript don't really mesh well with that: the more external domains you involve in a webpage, the worse the experience is. So I keep the images here to make it work as well as possible, and link back to the source URL in the `.liquid` files (which stick around when Elventy builds the `.html` files).
* `censorpandas/` - Content with the NC-17 rating has been given [the RTA label](<https://www.rtalabel.org/>).
* `disablejs/` - Favicons for various popular websites; used with the scare tactics popup from [https://disable-javascript.org](<https://disable-javascript.org>).
* `signal.png` - Signal QR code. Used on `/contact` and `/signal`.
